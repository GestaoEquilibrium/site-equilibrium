# Site Equilibrium Medcenter

Site institucional da Equilibrium Medcenter (Uberlândia/MG), publicado pelo GitHub Pages em
https://equilibriummedcenter.site

- `index.html`: a página inteira (HTML + CSS + JS)
- `assets/`: logo, favicon e fontes
- `CNAME`: domínio próprio usado pelo GitHub Pages

Para atualizar: edite os arquivos, faça commit e envie (`git push`). O site se atualiza em cerca de 1 minuto.
